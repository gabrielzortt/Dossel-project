Metodologia

De onde vêm os números

FOGO

NASA FIRMS

Detecções térmicas dos sensores VIIRS (Suomi-NPP/NOAA-20) via API pública da NASA, atualizadas a cada poucas horas. O comparativo ano a ano usa a fonte histórica padrão da mesma API.

FLORESTA

INPE / PRODES & DETER

PRODES mede o desmatamento consolidado por corte raso uma vez por ano; DETER emite alertas diários usados como estimativa do ano corrente até a consolidação oficial.

CLIMA

Open-Meteo

Reanálise e previsão numérica de código aberto, combinando modelos meteorológicos globais e regionais, incluindo a API de vazão de rios (Global Flood Awareness System).

Dossel

Painel de monitoramento independente. Dados de satélite: NASA FIRMS, INPE/PRODES-DETER, Open-Meteo. Não substitui boletins oficiais.
